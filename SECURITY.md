# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](../../security/advisories/new) for this repository. Don't open a public issue. We aim to acknowledge reports within five working days.

Include what you found, the steps to reproduce it, and the impact you expect. We'll keep you updated while we fix it and credit you in the advisory unless you'd rather stay anonymous.

## Supported versions

Only the `main` branch, which is what runs in production, receives security fixes.
